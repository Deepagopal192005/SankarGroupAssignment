# FlowPilot — SaaS Landing Page

A responsive SaaS landing page created for the **Sankar Group Front-End Development Internship Assignment**.

## Product concept
FlowPilot is an invented productivity SaaS for growing teams. It combines project planning, task management, lightweight automation, and progress visibility in one focused workspace.

## Technologies
- HTML5
- CSS3 (custom responsive layout, CSS animations, grid/flexbox)
- Vanilla JavaScript
- Google Fonts (DM Sans + Space Grotesk)

## Included sections
- Responsive navigation bar with mobile menu
- Hero section with product dashboard illustration
- Customer/logo strip
- Three feature cards
- How it works section
- Three pricing packages
- Contact / demo request form
- Footer

## Functional interactions
- Navigation links smoothly scroll to the relevant sections.
- CTA buttons lead to the relevant page sections.
- Mobile navigation opens/closes with JavaScript.
- Demo form validates name, email, and team size.
- Successful form submission displays a confirmation message without a backend.

## Run locally
1. Download or clone this project.
2. Open `index.html` in a browser.
3. No build step or backend is required.

For the best local experience, you can also serve the folder with any simple static server.

## Design choices
The design uses a calm cream/forest-green palette to communicate clarity and trust while the lime accent adds energy to important actions. A dashboard-style hero visual makes the SaaS concept understandable immediately without relying on external product screenshots. Cards, rounded corners, generous whitespace, and a strong typographic hierarchy keep the interface easy to scan. Responsive CSS changes the multi-column layouts into a mobile-friendly single-column experience. The main interaction challenge was keeping the form and mobile navigation functional without a backend, which was handled with lightweight vanilla JavaScript validation and state changes.
